# Word Pair Replace - Electron App

This is a desktop version of the Word Pair Replace tool built with Electron.

## Features
- Text replacement using predefined sets
- Quick replacement without creating sets
- Import/export functionality
- Dark mode support
- Undo functionality
- Transcript matching tool

## Getting Started

### Prerequisites
- Node.js installed on your system

### Installation
1. Clone or download this repository
2. Navigate to the ElectronApp directory
3. Run `npm install` to install dependencies

### Running the Application
1. Run `npm start` or `electron .` to start the app

## Development
To run in development mode:
```
npm run dev
```

## Building
To build a distributable package:
```
npm run build
```

## Running the App
To run the application:
1. Open a terminal/command prompt in the ElectronApp directory
2. Run `npm install` to install dependencies
3. Run `npm start` to start the app

## Files Structure
- `index.html` - Main HTML file
- `app.js` - Application logic
- `styles.css` - Styling
- `main.js` - Electron main process
- `package.json` - Application metadata and dependencies
